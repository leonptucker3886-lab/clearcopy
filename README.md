# ClearCopy

ClearCopy (beta v0.2) is a website proofreading desk.

Paste a page URL or a sitemap.xml URL and ClearCopy checks each page for:

- Spelling mistakes and repeated words
- Readability (reading grade)
- Title, meta description and H1 tags
- Whether the affiliate disclosure appears **before** the first Amazon link

Results can be exported as a CSV file.
